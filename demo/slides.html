Beyond Route 717A: Causal Kalman Ratio Filter on Unmodelled Routes

Per-Stretch, Per-Day State Update (planner/rides.py)
z = clip(actual / scheduled, 0.35, 3.0)
K = v / (v + R)             (Q = 0.01, R = 0.05)
s ← s + K · (z − s)      (v₀ = 1.0)
v ← (1 − K) · v + Q       d̂ = max(1, sched · s)
  • 717A untouched: Rung 4 LightGBM + split-conformal still serves covered 717A legs.
  • Live speed tier stays first: fresh VehiclePositions run ahead of the filter in live mode.
  • Strictly causal: seeded from prior-day median ratio; updates only on available_at < as_of_ts.
  • Clean degradation: falls back to historical_fallback, then exact timetable when empty.
Honest caveat: Measured offline against reconstructed October ground truth (5 train/holdout pairs: 27.4–28.7% gain). Live check covers 717A only, so unmodelled-route gains are not live-verified yet.
